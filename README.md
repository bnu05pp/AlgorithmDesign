# 算法设计与分析

## 课程简介

### 课程概述

计算机算法作为计算机解决实际问题的主要手段，是大数据等专业学生需要掌握的核心技能之一。算法设计与分析课程在数据结构课程的基础上，进一步剖析各类主要算法的问题描述、主要思想、基本原理和应用场景，使得学生不仅能掌握当前主要算法技术的工作原理，而且能理解该算法产生的背景和设计理念，使其能灵活运用这些技术，结合实际情况设计合适的算法解决问题。
